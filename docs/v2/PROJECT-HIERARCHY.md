# 大项目与分集流程更新

- 新建大项目时上传 TXT / MD / DOCX / PDF 总剧本，或直接粘贴。总剧本与分析保存在大项目。
- Codex 初步概括故事与制作重点，返回分集原文行号。服务端校验边界后建立分集，保留原文，不生成替代剧本。无法确定集数时允许手动添加。
- 集列表使用编号整行列表。自动识别的集点击上传本集素材；手动新增集可同时上传原片与资产。
- 重新分析不重复创建同名集，不覆盖已有集的剧本或制作成果。旧工程保留为未归组已有集。
- 验证：34 项已有测试通过；新增大项目分集、重复分析、越界保护、持久化测试通过。浏览器跑通总剧本上传、自动分集、手动增集上传以及原有制作流程；生产构建通过。
- 流程验收使用显式模拟 Codex 返回，未进行真实模型质量验证或视频收费生成。
