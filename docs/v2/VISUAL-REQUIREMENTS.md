# 画面要求分层调整

- 大项目：仅设置统一风格与质感；在大项目左侧编辑。基础实拍融合规则内置，不要求手动填写。
- 本集：影调与光影基准；在制作页顶部「本集 / 场景光影」编辑。
- 场景：按本集场景名称设置影调与光影，仅对同场景镜头生效。
- 镜头：生图详情和视频工作台「本段逐镜画面要求」填写独立要求。
- 上传页只保留本集剧本、原视频、素材，三栏固定等高，长内容在栏内滚动。

当前要求会进入 Codex 编译与生图输入，也会在视频提交时写入请求快照，覆盖旧提示词中的过期分层要求。修改会更新相关镜头版本，旧候选保留并标记需要复核；不会自动重新付费生成。

验证：36 项测试通过，类型检查通过；浏览器验证三栏等高及各级编辑入口。未打包桌面应用、未调用真实收费生成。旧集 brief/look 数据保留，look 作为本集光影基准，不自动升格为大项目风格。

## 基础规则内置修正

依据指定源 Skill v4.2.2 及 source_authority_rules / project_specific_overrides，把原演员身份、可靠摄影、表演动作、接触受力、原声时序、参考素材职责、场景重投影、按场地重光、VFX依据、候选边界和有依据的摄影例外集中为 fusion-rules.ts。静态、视频及整集编译共享该基线。旧 visualBrief 仅保留存储，不再作为新提示词输入；不修改 Skill 源文件。此修正不代表已经实现 Skill 的全部自动QC门禁。
