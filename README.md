# 与光 · 实拍工作台

一台电脑上运行的 AI 实拍融合工作台：Electron 桌面窗口 + React 界面 + 本地 Node 服务 + SQLite + FFmpeg。项目素材和任务记录保存在本机，Codex 使用本机已有登录；视频生成使用设置中配置的 Ark / ModelArk 兼容接口。

## 启动

在 Finder 双击 **启动工作台.command**。本机已安装依赖并构建后，它会直接打开桌面窗口。

开发命令：

```sh
npm ci
npm run build
npm run desktop:install
npm run desktop
```

浏览器模式使用 `npm start`，打开 http://127.0.0.1:4318。界面开发可另开 `npx vite`。浏览器模式和桌面模式不能同时占用同一个数据目录。

需要 Node 22+、FFmpeg/ffprobe；Codex CLI 已登录。设置中可以修改可执行文件路径。DOCX 使用 Python 标准库读取，PDF 使用 Python pypdf；当前电脑已验证可用。项目代码不读取或复制 Codex 的登录密钥。

## 第二版制作流程

1. 从项目页新建大项目，上传或粘贴完整总剧本；Codex 初步分析并自动识别集数。
2. 在横排集列表打开某集上传素材，或手动添加集并同时上传该集原视频和资产。已有未归组的集保留。
3. 在三个独立区域导入原视频、剧本和资产，补充改造目标，点击一次开始自动整理。
4. Codex 先理解素材，再自动拆镜、提取每镜第一帧、关联资产并编译分镜与视频提示词。进度按阶段显示，失败可重试，不自动冒充准备完成。
5. 自动进入分镜图工作台。按首帧卡片选镜、生成与筛选候选，提出修改或人工导入；高级提示词按需展开。只有关键歧义需要纠正，无需对每镜反复勾选常规确认。
6. 进入独立视频工作台，可跳过生图。自动组段与提示词编译，调整下方时间线，检查后点击生成；系统自动准备实际提交视频。
7. 在双屏中审片、调整映射和成片范围，提出反馈，修订后生成下一版并导出。

素材板可以返回查看原片、剧本、资产及分析。已存在的第一版项目保留历史记录，可继续制作或重新自动整理，不会静默清空旧版本。

产品审核与第二轮实现范围见 [第二轮审核及计划](docs/v2/REVIEW-AND-PLAN.md)，验收按 [产品验收标准](docs/v2/ACCEPTANCE.md) 执行。

## 数据与恢复

默认数据目录为项目内 `.workbench/`，可用 `WORKBENCH_DATA_DIR` 环境变量指定其他磁盘目录。

- `workbench.sqlite`：集、素材索引、镜头、剪辑、版本、反馈、任务及最近 30 次状态快照。
- `imports/`：导入副本；`proxies/`：浏览器预览代理。
- `frames/`、`analysis-frames/`：截帧与分析证据；`ai/`：Codex 输出和事件日志。
- `segments/`：提交给视频服务的原片段；`takes/`：下载的生成版本。
- `exports/`：成片与 JSON 项目清单；`requests/`：去除密钥和内联二进制的请求记录。
- `secrets.json`：仅本机账户可读写的 API Key 文件（权限 0600），不写入 SQLite 或项目导出。

备份请在退出工作台后复制整个 `.workbench/`。项目 JSON 是制作清单，引用本机文件；单独导出 JSON 不包含媒体，也不是跨机搬迁包。不要只备份数据库而丢掉素材目录。

本地处理中断后可以重试。已取得远端 ID 的视频任务可以恢复查询；提交状态未知的任务禁止自动重新生成，需要先在提供商控制台查明任务 ID。暂停本地查询不会取消提供商的生成或计费。

## 验证与当前边界

- `npm test`：媒体处理、API 请求契约、持久化、恢复、鉴权、完整本地制作链路。
- `npm run build`：严格 TypeScript 检查与生产构建。
- `npm run test:ui`：第二版新建、分类上传、自动准备、选图、视频双屏与时间线验收（显式模拟 AI 返回）。
- `npx tsx scripts/timeline-smoke.ts`：隔离媒体工程的剪辑、手动映射、裁剪与刷新恢复。
- `npx tsx scripts/desktop-smoke.ts`：Electron 真实启动验收；运行前退出其他工作台实例。
- `npm run smoke -- /绝对路径/原视频.mp4`：从真实素材提取短片，在隔离数据目录验证导入、组段、对齐和导出。测试副本明确标记为非 AI 生成。
- [AI 接入验证](docs/AI-INTEGRATION.md)：Codex 文本与真实生图证据、官方视频 API 文档和已验证范围。

视频 API 的真实收费生成尚未验证，因为尚未取得凭证。接口测试不代替真实提供商验收；只有使用相同 Ark / ModelArk 请求与上传协议的 Base URL 才兼容。第三方代理改变协议时需要适配，不能保证只改地址就通用。

当前使用切点与时间约束提供对齐建议；可以手动配对/删除映射。映射仅用于对比，不会暗中改变成片速度。生成时长与原声不同的导出会明确阻止使用原声音轨，避免静默破坏口型同步；可选择生成音轨，或校准后人工导入。

预览代理和默认输出为 SDR H.264/AAC，用于制作与审片；不包含 HDR 色彩管理、专业调色或复杂多轨混音。
